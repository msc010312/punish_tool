# 시연 영상 시나리오 (3~5분)

> 목적: "측정→언어 분리"와 "AI 휴먼(아바타+음성+코치)"을 3~5분에 보여준다.
> 촬영은 화면 녹화(OBS 등) + 마이크. 각 씬의 **화면/자막/나레이션**을 그대로 따라 찍으면 된다.

---

## 씬 0 — 타이틀 (0:00~0:15)
- **화면**: 프로젝트 최종 보고서(HTML) 첫 화면 또는 솔 아바타 정지컷.
- **자막**: `Punish Tool — 길티기어 스트라이브 AI 코치`
- **나레이션**: "대전격투 리플레이를 넣으면, AI 휴먼 솔 배드가이가 그 순간 뭘 했어야 이겼는지
  프레임 단위로 짚어 주는 로컬 오프라인 코치입니다."

## 씬 1 — 문제 제기 (0:15~0:45)
- **화면**: Dustloop 프레임표 스크린샷(빽빽한 숫자표) → 리플레이 한 장면.
- **자막**: `막혔을 때, 나는 무엇으로 반격되는가?`
- **나레이션**: "이 답은 방대한 프레임표에 흩어져 있어 대전 중엔 못 찾습니다.
  그래서 영상에서 그 순간을 자동으로 찾아 해답을 주기로 했습니다."

## 씬 2 — 영상 분석 (0:45~1:45) **[핵심]**
- **화면**: GUI 실행 → [AI 코치] 탭에 리플레이 영상 드롭 → 진행바 → 분석 완료.
  - 좌측 요약, 중앙 타임라인에 **피격/COUNTER/PUNISH** 마커가 찍히는 것 보여주기.
- **자막**: `① HUD 자가보정으로 이벤트 추출 → ② 프레임데이터로 확정반격 계산`
- **나레이션**: "체력바 색을 자가보정해 언제 누가 맞았는지 이벤트를 뽑고(①),
  프레임데이터로 그 순간 확정 반격이 뭔지 계산합니다(②). 영상에서 **사실만** 추출합니다."

## 씬 3 — AI 코치 대화 (1:45~2:45) **[핵심]**
- **화면**: 코치가 분석 결과를 채팅으로 설명 → 사용자가 추가 질문 입력.
  - 예) "솔 5K 발생 몇 프레임이야?" → "5프레임이야. 빠르니까 견제로 써"
  - 예) 근거에 없는 질문 → 코치가 **"그건 데이터에 없어"**라고 답하는 장면(제1원칙).
- **자막**: `측정된 사실만 말한다 — 모르면 침묵, 거짓말 금지`
- **나레이션**: "코치는 추출된 사실과 번들 지식(RAG)에 있는 숫자만 말합니다.
  없는 걸 물으면 지어내지 않고 모른다고 답합니다. 이걸 코드의 숫자 가드가 최종 보증합니다."

## 씬 4 — 멀티모달: 아바타 + 음성 (2:45~3:45)
- **화면**: 솔 3D 아바타 위젯(립싱크·깜빡임·표정) + JP 솔 음성 샘플 재생.
  - `tts/samples/sol_jp/sample_00~03.wav` 재생하며 아바타 입 움직임 보여주기.
- **자막**: `게임 모델 추출 → three.js 실시간 3D / SBV2 한국어 개조 TTS`
- **나레이션**: "게임 3D 모델을 추출해 실시간 아바타로 세우고, 음성은 Style-Bert-VITS2를
  NDC26 방식으로 한국어까지 개조했습니다. 일본어 솔 음성은 학습을 마쳐 지금 들리는 대로 나옵니다."

## 씬 5 — 기술 하이라이트 (3:45~4:30)
- **화면**: 웜스타트 91% 전이 도식 / 한국어 G2P 변환 예시(삼일전→사밀전) / 배포본 실행.
- **자막**: `사전학습 91% 재사용 · 완전 로컬 · 설치/터미널 없음`
- **나레이션**: "한국어 기반모델은 일본어 사전학습의 91%를 물려받아 소규모 자원으로 학습합니다.
  전체가 사용자 PC에서 오프라인·무료로 돌고, 배포본은 더블클릭 한 번으로 실행됩니다."

## 씬 6 — 마무리 (4:30~5:00)
- **화면**: 아키텍처 다이어그램(README의 mermaid) 또는 솔 아바타 클로즈업.
- **자막**: `측정은 정확하게, 코칭은 사람처럼`
- **나레이션**: "정확한 측정과 사람 같은 코칭을 분리해, 틀린 정보 없이 실력 향상을 돕는
  AI 휴먼 코치. 이상입니다."

## 촬영 체크리스트
- [ ] GUI 실행 화면(코치 탭 + 분석 탭)
- [ ] 리플레이 영상 1개(타임라인 마커가 잘 찍히는 것)
- [ ] 코치 정상 답변 1개 + "데이터 없음" 답변 1개
- [ ] 아바타 위젯 동작(`avatar3d/index.html` 또는 GUI 내장)
- [ ] JP 음성 샘플 4종 재생
- [ ] 배포본 더블클릭 실행 장면

## 편집 메모
- 길이 목표 4~5분. 씬 2·3(분석·코치)에 시간 배분을 가장 크게.
- 자막은 화면 하단, 나레이션과 동일 문장 권장.
- BGM은 저작권 free. 게임 음성 샘플엔 "게임 음성 기반 합성(교육용)" 자막 1회 노출.
